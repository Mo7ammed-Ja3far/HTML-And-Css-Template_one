## 📖 Project Overview

**Leon** is a modern, minimalist landing page tailored for creative digital agencies.

As my very first milestone in software engineering, I intentionally built this project **without any CSS frameworks** (like Bootstrap or Tailwind) or JavaScript. The goal was to deeply understand how the browser renders elements, how to structure semantic markup, and how to master CSS layout modules natively.

---

## ✨ Key Features

- **Semantic Architecture:** Built with clean HTML5 semantic tags for better SEO and accessibility.
- **Fluid Responsiveness:** Fully functional across all viewports (Mobile, Tablet, Desktop) using custom CSS Media Queries.
- **Modern Layouts:** Heavy utilization of CSS Flexbox for alignment and spacing.
- **Modular Styling:** Organized CSS structure using variables (`:root`) for color themes and typography, ensuring easy future maintenance.
- **Optimized Assets:** Integrated Google Fonts (_Work Sans_) and Font Awesome vectors for lightweight, scalable iconography.

---

## 🛠️ Tech Stack & Tools

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, CSS Variables, Media Queries)
- **Typography & Icons:** Google Fonts, Font Awesome
- **Version Control:** Git & GitHub

---

## 🧠 Key Learnings

Building this project provided a rock-solid foundation in front-end development. I learned how to:

1. Translate a raw design into a functional web page with pixel-perfect accuracy.
2. Handle cross-browser reset strategies using `normalize.css`.
3. Create scalable, maintainable CSS without relying on utility classes or external libraries.
4. Manage content overflow and implement mobile-first design thinking.

## 🚀 Getting Started

To run this project locally, simply clone the repository and open the HTML file:

```bash

git clone [https://github.com/Mo7ammed-Ja3far/HTML-And-Css-Template_one.git](https://github.com/Mo7ammed-Ja3far/HTML-And-Css-Template_one.git)

# Navigate to the project directory
cd HTML-And-Css-Template_one

# Open index.html in your default browser (macOS/Linux/Windows)
```
